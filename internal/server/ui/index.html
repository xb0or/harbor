核心理念

能等就等，不能等才报错。

普通 Gateway 在资源耗尽时立即返回 429。Harbor 不一样——它把请求放进队列，等资源恢复后继续执行，客户端最终拿到正常结果。只有在真正无法恢复时才返回错误。

错误收敛

核心特性

为自用场景恰到好处的设计

01
⚓

排队挂起，不轮询

请求达到并发 / RPM / Token 限制后进入队列，Harbor 挂起原 HTTP 请求等待资源恢复后继续执行。不采用 202 + ticket 轮询模式，官方 OpenAI SDK 无需任何改动即可接入——只改 base_url 和 API Key。排队期间对 SSE 请求发送心跳保活，非 SSE 使用连接层 keepalive。

02
🔀

多上游故障转移

支持多个 Provider 和多凭证。上游 429 / 5xx / 超时时自动切换，带冷却与重试预算，杜绝无限循环。

03
🎫

Harbor Key 管理

创建、封禁、解封、配置额度与允许模型。Key 仅存哈希，明文只返回一次。

04
📊

全链路统计

每个请求都有 Request ID 贯穿入队、等待、出队、执行。今日请求数、成功 / 失败、Token 用量、P50 / P95 等待时间、TPS 统计。单请求可查排队时长、上游尝试次数、最终状态与 Token 消耗。

05
🔒

安全收敛

对外错误绝不透传供应商名称、上游 Key、原始报文、内部 URL 与堆栈。管理接口独立凭证，请求体大小限制，SSRF 防护。

06
📦

一个二进制 + 一个配置文件

Go 实现，SQLite 持久化，内存队列与计数器。部署尽可能简单——harbor --config harbor.yaml 即可运行。不追求"功能最多的 AI Gateway"，只追求把"不急着报 429"这件事做好。

快速接入

三步接入 Harbor

官方 OpenAI SDK 只需修改 base_url 和 API Key 即可。请求超限自动排队，上游错误统一收敛。

Node.js · openai

# 1. 安装 OpenAI SDK（已装可跳过）
pip install openai

# 2. 修改 base_url 与 api_key 即可接入
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8080/v1",
    api_key="hr-你的HarborKey",  # 管理台创建
)

# 3. 像往常一样调用——超限自动排队，不是 429
resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "你好"}],
    stream=True,  # 排队期间发送 SSE 心跳
)
for chunk in resp:
    print(chunk.choices[0].delta.content, end="", flush=True)
// 1. 安装 OpenAI SDK
npm install openai

// 2. 修改 baseURL 与 apiKey
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://127.0.0.1:8080/v1",
  apiKey: "hr-你的HarborKey",
});

// 3. 超限自动排队，流式请求排队期间发心跳
const stream = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "你好" }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0].delta.content ?? "");
}
# 非流式
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Authorization: Bearer hr-你的HarborKey" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o","messages":[{"role":"user","content":"你好"}]}'

# 流式（排队期间收到 SSE 心跳 : queue heartbeat）
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Authorization: Bearer hr-你的HarborKey" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o","stream":true,"messages":[{"role":"user","content":"你好"}]}'
